Point-to-Point connection between two or more [[Virtual Private Clouds (VPC)]].  Each connection is exclusive between the two [VPC] points, which means, creating a network of a large number of [VPC] would require multiple lines of connections and a lot more work if the intent was to connect all of them. 
- Point-to-point connection between two [[Virtual Private Clouds (VPC)]]
- Utilizes the [Private AWS Network Backbone] as transport
- Easy and quick setup between two VPCs
- High speed, lowest latency
- No overlapping of [CIDR Blocks]
- Cost Structure: No hourly fee; pay is only for data transfer across AZs
