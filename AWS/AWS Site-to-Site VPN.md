Encrypted, cost-effective backup or primary tunnel from [[on-premises]] data center to [[Virtual Private Clouds (VPC)]] creating a hybrid cloud environment.
- Utilizes [[IPsec Virtual Private Network (VPN) Connection]]
	- On AWS cloud side [[Virtual Private Gateway]]
	- On-Premise Side [[Customer Gateway (CGW)]]
- Low. Fast, API-driven software configuration
- Unpredictale internet latency; limited up to 1/25 Gbps per tunnel
- Cost Structure: Low hourly connection charge + standard egress data transfer.
