
Problem Solved: Complexity for small projects. If EC2 is too complex for a simple WordPress site or a small dev environment, [[Amazon Lightsail]] provides a "click-and-go" experience with a predictable monthly price that bundles compute, storage, and networking.

- Virtual servers, storage, databases, and networking
- Low & predictable pricing
- Simpler alternative to suing EC2, RDS, ELB, EBS, Route 53…
- Great for people with little cloud experience:
- Can setup notifications and monitoring of your lightsial resources
- Use cases:

- Simple Web applications (has templates for LAMP, Nginx, MEAN, [Node.js](http://node.js)…)
- Dev/Test environment
- Has high availability but no auto-scaling, limited AWS integrations.
