**

Free service that is activated for every AWS Customer to protect from DDoS attack (Distributed Denial of Service)

- AWS Shield Standard protects from attacks such as SYN/UDP Floods
	- Layer 3/Layer 4 attacks
- AWS Shield Advanced
	- Optional DDoS mitigation service ($3000 per month per organization)
	- Protects against attack on:
		- [[EC2 instances]]
		- [[AWS Elastic Load Balancer (ELB)]]
		- [[Amazon Cloudfront (Content Delivery Network (CDN))]]
		- [[AWS Global Accelerator]]
		- [[AWS Route 53]]
- Protects against higher fees during usage spakes
