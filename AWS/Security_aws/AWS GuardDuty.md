[[AWS GuardDuty]] is a threat detection service that continuously monitors for malicious activity and unauthoried behavior to protect AWS accounts, workloads, and stored date in [[Amazon Simple Storage Service (S3)]].  This service utilizes machine learning, anamaly detection, and integrated threat intelligence to identify potential threats.
- Operates at the network and API level using [[VPC Flow Logs]] and [[AWS CloudTrail]]
- Foundational Data Sourced monitored by [[AWS GuardDuty]]
	- [[AWS CloudTrail]]
	- S3 Data Events
	- [[VPC Flow Logs]]
	- DNS Logs
