## File exploration
We're familiar with [[Graphical User Interface (GUI)]] and using the mouse or touch screen to navigate through files. The [[Graphical User Interface (GUI)]] utilizes the file explorer application in which files are stored in a hierarchical linear system. 

The other way to explore is using the [[Command Line Interface (CLI)]] which uses the [[linux/unix]] framework/language to communicate directly to the communicate with the operating system. This is much faster if you know how to issue the commands appropriately. 
- Note: spaces separate segments in the command or in some cases between a command and an argument. **DON'T USE SPACING IN NAMING YOUR FILES**
	- Space still registers as [[Binary Code]] or computer language
