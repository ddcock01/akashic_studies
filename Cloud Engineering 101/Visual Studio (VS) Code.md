[Lightweight code editor built by Microsoft that acts as a full development environment.](https://www.youtube.com/watch?v=bj6QSx22zXs)
- supports multiple languages
- 1000 extensions
	- Add support for new program languages
	- debugging tools
	- enhance productivity
	- Improve formatting
- debugging integration with Git
	- Version Control Capability
- Supports a multitude of Terminals
It is the combination of all of these features that make [[Visual Studio (VS) Code]] so useful for your workplace as it is a one stop shop. This eliminates the necessity for traveling between multiple windows/applications/folders.
